# Securing the WordPress Configuration File

## Overview

The `wp-config.php` file contains sensitive configuration information for WordPress, including database credentials and security keys.  

By default, this file is located in the **WordPress root directory**, which is accessible through the web server. Moving this file outside of the web root directory helps reduce exposure and adds an additional layer of security.

---

# WordPress Configuration File Hardening

## Step 1: Navigate to the WordPress Root Directory

For convenience, navigate to the WordPress web root directory before performing the configuration changes.

```bash
cd /var/www/html
```

Although these commands can be run from other directories, working directly inside the WordPress directory helps avoid confusion.

---

## Step 2: Verify the Configuration File Location

List the contents of the directory to confirm that the `wp-config.php` file exists in the WordPress root directory.

```bash
ls -la
```

You should see:

```
wp-config.php
```

This confirms that the configuration file is currently located inside a **web-accessible directory**, which may present a security risk.

---

## Step 3: Move the WordPress Configuration File

Move the configuration file outside the web root directory.

```bash
mv wp-config.php /var/www/
```

### Why This Improves Security

Moving the configuration file:

- Removes it from the **public web directory**
- Prevents direct access from a **web browser**
- Adds another layer of protection against attackers

### Troubleshooting

If you receive the error:

```
mv: cannot move 'wp-config.php' to '/var/www/wp-config.php': Permission denied
```

This indicates that your current user **does not have permission** to move the file.

You will need to troubleshoot and correct the permission issue before continuing.

---

## Step 4: Verify the File Was Moved

Navigate to the `/var/www/` directory and confirm the file was successfully moved.

```bash
cd /var/www/
```

```bash
ls -la
```

You should now see:

```
wp-config.php
```

This confirms that the WordPress configuration file has been moved outside the WordPress root directory.
