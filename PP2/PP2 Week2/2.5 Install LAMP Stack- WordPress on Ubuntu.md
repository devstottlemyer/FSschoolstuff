# LAMP Stack Installation (Ubuntu)

The steps below correspond with screenshots required for the **Milestone assignment** (with minor exceptions).

---

# System Preparation

## Step 1: Update Ubuntu

```bash
sudo apt-get update -y
```

---

## Step 2: Upgrade Ubuntu Packages

```bash
sudo apt upgrade -y
```

---

## Step 3: Install Nano

```bash
sudo apt install nano -y
```

---

## Step 4: Install Git

```bash
sudo apt install git -y
```

---

# Apache Web Server

## Step 5: Install Apache

```bash
sudo apt install apache2 -y
```

This installs the **Apache2 web server package** and required configuration files.

---

## Step 6: Create Firewall Profile for Apache

Allow HTTP and HTTPS traffic through the firewall.

```bash
sudo ufw allow in "Apache Full"
```

This opens:

- TCP 80 (HTTP)
- TCP 443 (HTTPS)

---

## Step 7: Test Apache Installation

Open a browser and navigate to:

```
http://10.10.229.12
```

You should see the **Apache Default Page**.

---

# MySQL Database Server

## Step 8: Install MySQL Server

```bash
sudo apt install mysql-server
```

⚠️ **Recommendation:**  
Create a **snapshot of your virtual machine** at this stage so you can revert if configuration problems occur later.

---

## Step 9: Log in to MySQL

```bash
sudo mysql
```

---

## Step 10: Change MySQL Root Password

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'insert_random_password_here';
```

⚠️ **Important:**  
Document your MySQL passwords in your inventory documentation. These passwords **cannot be recovered** if forgotten.

---

## Step 11: Flush Privileges

```sql
FLUSH PRIVILEGES;
```

---

## Step 12: Exit MySQL

```sql
exit
```

---

# PHP Installation

## Step 13: Install PHP

```bash
sudo apt install php
```

This installs the base **PHP interpreter** required for the LAMP stack.

---

## Step 14: Edit the `sources.list` File

```bash
sudo nano /etc/apt/sources.list
```

⚠️ **Note:**  
Add `universe` to the end of all repository URLs if it is missing.  
Do **not delete or replace** anything in the file.

---

## Step 15: Update Package Lists

```bash
sudo apt update -y
```

This refreshes the repository list.

---

## Step 16: Install Required PHP Libraries

```bash
sudo apt install php libapache2-mod-php php-mysql
```

These packages allow PHP to work with **Apache** and **MySQL**.

---

## Step 17: Install PHP Extensions

WordPress requires additional PHP extensions.

```bash
sudo apt install php-curl php-gd php-xml php-mbstring php-xmlrpc php-zip php-soap php-intl
```

---

## Step 18: Enable Apache Rewrites

Enable URL rewrites for cleaner and more user-friendly URLs.

```bash
sudo a2enmod rewrite
```

---

## Step 19: Restart Apache

Apply the changes by restarting Apache.

```bash
sudo service apache2 restart
```

Alternative command:

```bash
sudo systemctl restart apache2
```

---

# Testing PHP

At this point, your system should have:

- Apache Web Server
- MySQL Database
- PHP Language Support

Next, you will verify that PHP is functioning properly.

---

## Step 20: Create a Test PHP Page

Create a file called **test.php** in the web root directory.

```bash
sudo nano /var/www/html/test.php
```

Insert the following code:

```php
<?php phpinfo(); ?>
```

Save the file.

---

## Step 21: Test the PHP Page

Open Firefox on your Ubuntu VM and navigate to:

```
http://10.10.229.12/test.php
```

If the **PHP information page** appears, your LAMP stack is functioning correctly.
