# MySQL WordPress Database Setup

The steps below are designed to correspond with screenshots required for the **Milestone assignment** (with minor exceptions).

---

## Step 1: Log in to MySQL
Use the following command to log in to MySQL.

This login uses the permissions previously granted to **`'root'@'localhost'`** in the previous assignment.

```bash
mysql -u root -p
```

---

## Step 2: Create a WordPress Database
While inside MySQL, create the WordPress database using the command below.

⚠️ **Note:** Pay attention to capitalization.

```sql
CREATE DATABASE WordPressDB DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

---

## Step 3: Create a WordPress User
Create a new user account that WordPress will use to access the database.

Be sure to **document the random password** you create in your inventory documentation.

```sql
CREATE USER 'WordPressUser'@'localhost' IDENTIFIED BY 'insert_random_password_here';
```

---

## Step 4: Grant Permissions to the WordPress User
Grant the WordPress user full privileges to the WordPress database.

```sql
GRANT ALL ON WordPressDB.* TO 'WordPressUser'@'localhost';
```

---

## Step 5: Flush Privileges
Reload the MySQL privilege tables from disk so that the changes take effect.

```sql
FLUSH PRIVILEGES;
```

---

## Step 6: Exit MySQL
Exit the MySQL session using the following command.

```sql
exit
```
