# WordPress Setup Instructions

## Step 1: Navigate to the WordPress Site
Open a browser and go to:

http://10.10.229.12

You should see the WordPress installation page.

---

## Step 2: Connect the MySQL Database
Enter the database information you created earlier:

- **Database Name**
- **Database User**
- **Database Password**

⚠️ **Important:**  
Do **NOT** use the MySQL root account (`root@localhost`).

---

## Step 3: Run the WordPress Installation
Complete the WordPress installation process on your **Ubuntu VM**.

---

## Step 4: Create an Admin WordPress User
Follow the prompts in the WordPress installer to create an administrator account.

Record the following information in your **inventory documentation**:

- **Admin Username**
- **Admin Password**

Set the site name to:

**Ubuntu LAMP**

This will help identify which backend server is being used later when the site is connected to the **reverse proxy**.

---

## Step 5: Change the WordPress Theme
1. Log into the **WordPress Admin Dashboard**.
2. Navigate to **Appearance → Themes**.
3. Choose any of the **built-in themes** and activate it.

---

## Step 6: Create a Test Post
1. Create a **test post** on your WordPress website.
2. Add a **test comment** to the post.

This verifies that the website is functioning correctly.
