# Secure Shell (SSH) Remote Access Setup

## Introduction

**Secure Shell (SSH)** is a cryptographic protocol used for secure communication over an unsecured network. It creates an encrypted connection between two devices, typically a **client** and a **server**, allowing them to communicate safely over potentially insecure networks.

For this lab, SSH will be used to **securely access Rocky 8 virtual machines (VMs)** from the Ubuntu VM.

The SSH client used in this setup is **OpenSSH**, an open-source implementation of the SSH protocol that allows secure remote login and command execution.

---

# SSH Configuration Steps

## Step 1: Log in to Ubuntu

1. Start all virtual machines in **Proxmox**.
2. Log in only to the **Ubuntu VM**.

The Ubuntu VM will be used to remotely access the Rocky 8 machines.

---

## Step 2: Install the OpenSSH Client

Open a terminal on the Ubuntu virtual machine and install OpenSSH.

```bash
sudo apt install openssh-client -y
```

**Notes:**

- If you are logged in as the **root user**, the `sudo` portion of the command is not required.
- The `-y` flag automatically answers **"yes"** to any confirmation prompts during installation.

---

## Step 3: Connect to the Rocky 8 Virtual Machines

Use SSH to establish secure remote connections to both Rocky 8 servers.

### Connect to Rocky8-Docker

```bash
ssh root@10.10.229.11
```

### Connect to Rocky8-NginX

```bash
ssh root@10.10.229.10
```

**Explanation of the command:**

```
ssh root@IP_ADDRESS
```

- `ssh` → Initiates the SSH connection  
- `root` → The user account being used to log in  
- `@` → Separates the username from the host  
- `IP_ADDRESS` → The address of the remote system

---

## Step 4: Accept SSH Key and Enter Password

When connecting to the server for the **first time**, you will see a message asking if you trust the host.

Type:

```
yes
```

This will add the server’s SSH key to your **known_hosts** file.

After accepting the key, you will be prompted to enter the **password of the remote VM**.

Once the password is entered successfully, you will be logged into the remote Rocky 8 machine.

---

## Result

After completing these steps, you should be able to:

- Remotely access **Rocky8-Docker**
- Remotely access **Rocky8-NginX**
- Manage both systems securely from the **Ubuntu VM**
