# Rocky 8 Docker Installation and Configuration

## Overview
These steps guide you through preparing the **Rocky8-Docker virtual machine**, installing **Docker CE**, and deploying a **Ghost blog container**.

You will manage the Rocky 8 machines remotely from your **Ubuntu VM using SSH**.

---

# Step 1: Configure Hostnames and Verify IP Addresses

Log into your **Ubuntu VM** and verify IP addresses.

Rename the hostnames of the Rocky 8 VMs using **Network Manager Text User Interface (nmtui)**.

```bash
nmtui
```

You will **not log directly into the Rocky8-Docker or Rocky8-Nginx VMs**.  
All management will occur remotely from the **Ubuntu VM using SSH**.

### Example Hostnames

```
root@UbuntuCossin
root@DockerCossin
root@NginxCossin
```

Hostnames should include either:

- The **operating system + last name**
- The **function of the VM + last name**

---

# Step 2: SSH into the Rocky8-Docker VM

From your Ubuntu VM, establish an SSH connection to the Docker server.

```bash
ssh root@10.10.229.11
```

⚠️ Ensure hostnames are configured **before taking screenshots** for the assignment.

# Preparing Rocky8-Docker for Docker Installation

Ensure your system is updated and required packages are installed.

Run these commands **separately**:

```bash
sudo yum update -y
```

```bash
sudo yum install nano
```

```bash
sudo yum install epel-release -y
```

---

# Docker Installation

## Step 4: Install Required Package Manager Utilities

```bash
sudo yum install -y yum-utils device-mapper-persistent-data lvm2
```

The `-y` flag automatically answers **yes** to installation prompts.

---

## Step 5: Add the Docker Repository

```bash
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
```

This command adds the official **Docker CE repository**.

---

## Step 6: Install Docker Engine

```bash
sudo yum install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y
```

This installs the latest version of:

- Docker Engine
- Docker CLI
- Container runtime
- Build tools
- Docker Compose plugin

---

## Step 7: Verify Docker Installation

Check the installed Docker version.

```bash
docker -v
```

---

# Docker Initialization

## Step 8: Start Docker

```bash
sudo systemctl start docker
```

This starts the **Docker daemon service**.

---

## Step 9: Enable Docker at Boot

```bash
sudo systemctl enable docker
```

Then reboot the system:

```bash
reboot
```

---

## Step 10: Test Docker Installation

Run the **hello-world container** to confirm Docker is functioning.

```bash
sudo docker run hello-world
```

If successful, Docker will download the image from **Docker Hub** and run it.

---

# SELinux Configuration

## Step 11: Disable SELinux

Open the SELinux configuration file:

```bash
sudo nano /etc/selinux/config
```

Change the following line:

```
SELINUX=enforcing
```

To:

```
SELINUX=disabled
```

⚠️ Note:  
SELinux normally improves system security. It is disabled here only to prevent conflicts during the assignment.

---

## Step 12: Reboot the Virtual Machine

```bash
reboot
```

---

## Step 13: Verify SELinux Status

After rebooting, confirm SELinux is disabled.

```bash
sestatus
```

# Deploy the Ghost Docker Container

## Step 14: Install the Ghost Blog Container

Run the following command:

```bash
docker run -d --name ghost -p 3001:2368 -e url=http://10.10.229.11:3001 ghost
```

### Command Breakdown

| Option | Description |
|------|-------------|
| `docker run` | Creates and starts a new container |
| `-d` | Runs the container in detached mode |
| `--name ghost` | Names the container "ghost" |
| `-p 3001:2368` | Maps host port **3001** to container port **2368** |
| `-e url=http://10.10.229.11:3001` | Sets the Ghost application base URL |
| `ghost` | Specifies the Docker image |

After deployment, the Ghost blog will be accessible at:

```
http://10.10.229.11:3001
```
