# SELinux Configuration

## Step 5: Disable SELinux

Open the SELinux configuration file:

```bash
sudo nano /etc/selinux/config
```

Find the line:

```
SELINUX=enforcing
```

Change it to:

```
SELINUX=disabled
```

⚠️ Important:  
The value must be **disabled**, not **disable**.

---

## Step 6: Reboot the Rocky 8 VM

```bash
reboot
```

---

## Step 7: Confirm SELinux Status

After rebooting, verify SELinux is disabled:

```bash
sestatus
```

You should see:

```
SELinux status: disabled
```

---

# Firewall Configuration

## Step 8: Stop Rocky 8 Firewall

```bash
systemctl stop firewalld
```

---

## Step 9: Disable Rocky 8 Firewall

```bash
systemctl disable firewalld
```

⚠️ Note:  
This disables the **Rocky 8 firewall**, not the **firewall VM**.

# Nginx Installation

## Step 10: Install Nginx

```bash

```

---

## Step 11: Start Nginx

```bash
systemctl start nginx
```

---

## Step 12: Enable Nginx at Boot

```bash
systemctl enable nginx
```

---

## Step 13: Verify Nginx Status

```bash
service nginx status
```

You should see **"running"** (typically displayed in green).

# Nginx Configuration

## Step 14: Edit the Nginx Configuration File

Open the configuration file:

```bash
nano /etc/nginx/nginx.conf
```

Navigate to the appropriate location and insert the configuration code provided in your assignment instructions.

⚠️ Enter the configuration **exactly as shown** in the instructions.

# Ghost Container Reconfiguration (Docker Server)

## Step 16: Stop the Existing Ghost Container

Log into the **Rocky8-Docker VM** and stop the existing container.

```bash
docker stop ghost
```

If the container is already stopped, Docker may return an error.  
This is acceptable for the assignment.

---

## Step 17: Remove the First Ghost Container

```bash
docker rm [containerID]
```

Replace `[containerID]` with the container ID recorded earlier.

---

## Step 18: Create a New Ghost Container

```bash
docker run -d --name ghost -p 3001:2368 -e url=http://10.10.229.10/blog -e NODE_ENV=development -e database__connection__filename="/var/lib/ghost/content/data/ghost.db" -v ghost-data:/var/lib/ghost/content ghost
```

⚠️ Important:

- This is **one complete command**
- Pay close attention to:
  - spaces
  - quotation marks
  - double underscores (`__`)

---

## Step 19: Restart the Ghost Container

```bash
docker restart ghost
```

---

## Step 20: Locate the New Container ID

```bash
docker ps -a
```

Record the **new container ID** for the next step.

---

## Step 21: Update the Container Restart Policy

```bash
docker update --restart=always [containerID]
```

Replace `[containerID]` with the new Ghost container ID.

This ensures the container automatically restarts if the system reboots.
